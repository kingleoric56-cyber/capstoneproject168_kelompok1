Tentang Sistem Ini

Modified K-Nearest Neighbor + HSV + LBP

Modified K-Nearest Neighbor (MKNN) adalah pengembangan dari algoritma KNN tradisional dengan tambahan perhitungan nilai validitas data latih dan pembobotan (weighted voting) berdasarkan jarak Euclidean, sehingga lebih tahan terhadap data pencilan (outlier).

Fitur warna diambil dari ruang warna HSV (Hue, Saturation, Value) berupa mean, standar deviasi, dan skewness tiap komponen. Fitur tekstur diambil dari statistik histogram Local Binary Pattern (LBP): mean, variance, skewness, kurtosis, dan entropy.
